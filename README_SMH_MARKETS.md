# SMH Markets - FXPro Clone

## Описание проекта
Полный фронтенд-клон торговой платформы FXPro.com под брендом **SMH Markets**. 
Профессиональный многоязычный сайт для финансового брокера с современным дизайном.

## Реализованные функции

### ✅ Многоязычность
- **5 языков**: English, Polski, Čeština, Türkçe, Slovenčina
- Переключение языка через выпадающее меню в header
- Локализация всех текстов и интерфейса

### ✅ Страницы сайта
1. **Home** (`/`) - Главная страница
   - Hero секция с призывом к действию
   - Live ticker с ценами инструментов
   - Статистика (500K+ трейдеров, 2000+ инструментов)
   - Секции Features, Platforms, Markets

2. **Trading Platforms** (`/platforms`) - Торговые платформы
   - MetaTrader 4
   - MetaTrader 5
   - cTrader
   - SMH Edge (собственная платформа)
   - Сравнительная таблица функций

3. **Markets** (`/markets`) - Торговые рынки
   - Поиск инструментов
   - Фильтрация по категориям (Forex, Stocks, Crypto, Metals, Indices, Energy)
   - Карточки инструментов с ценами и изменениями
   - Кнопки Buy/Sell

4. **Account Types** (`/accounts`) - Типы счетов
   - Demo Account (бесплатно)
   - Standard Account ($100)
   - Pro Account ($500) - Рекомендуемый
   - VIP Account ($10,000)
   - Детальная таблица сравнения

5. **Trading Tools** (`/tools`) - Торговые инструменты
   - Калькулятор трейдера
   - Экономический календарь
   - Рыночный анализ
   - Технический анализ
   - Анализ настроений
   - Скринер рынка

6. **Education** (`/education`) - Обучение
   - Торговые гайды
   - Видео-уроки
   - E-книги
   - Вебинары
   - Курсы для начинающих, продвинутых и профессионалов

7. **About Us** (`/about`) - О компании
   - История компании
   - Ценности компании
   - Достижения и статистика
   - Команда руководителей

### ✅ Дизайн и UI/UX
- **Цветовая схема**: Красный (#ED1B23) как у FXPro + белый/серый
- **Компоненты**: Используются shadcn/ui компоненты
- **Адаптивность**: Полностью responsive дизайн (desktop, tablet, mobile)
- **Анимации**: Плавные hover-эффекты и transitions
- **Иконки**: Lucide React (профессиональные иконки)

### ✅ Технический стек
- **Frontend**: React 19
- **Routing**: React Router v7
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui
- **Icons**: Lucide React
- **State Management**: React Context (для языка)

- **Текст**: "SMH" (жирный) + "Markets" (light)

- **Primary**: #ED1B23 (FXPro Red)
- **Secondary**: White / Gray
- **Accent**: Red градиенты

## Особенности реализации

1. **Профессиональный финансовый дизайн** - Соответствует стандартам FXPro
2. **Моковые данные** - Все данные статичные (фронтенд only)
3. **Без backend** - Только frontend, кнопки не отправляют запросы
4. **Изображения** - Stock фото от Unsplash/Pexels для финансовой тематики
5. **SEO-friendly** - Семантическая разметка HTML
